# Memeplex Studio

## 中文

本仓库收录 Memeplex Studio 的源代码。这是一款以模因为主题的桌面模拟游戏，也是我在伦敦艺术大学（University of the Arts London）攻读 Computing in the Creative Industry (modular) 研究生课程期间开发的毕业设计。

## English

This repository contains the source code for Memeplex Studio, a desktop simulation game about memes. I developed it as my final project for the postgraduate Computing in the Creative Industry (modular) programme at University of the Arts London.
